容器部署

直接从 GitHub 拉取镜像

推送到 main 或打版本 tag 时，GitHub Actions 会自动构建多架构镜像。

一次性登录（私仓需要）
echo <PAT> | docker login ghcr.io -u Kylo94 --password-stdin
拉取指定版本
docker pull ghcr.io/kylo94/course-report-generator:1.4.0
用仓库提供的 compose 文件启动
docker compose -f docker-compose.ghcr.yml up -d
# 指定版本
CRG_IMAGE_TAG=1.4.0 docker compose -f docker-compose.ghcr.yml up -d

PAT 只需 read:packages 权限。数据卷挂载在 ./data，升级镜像不会丢设置。
