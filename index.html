使用流程

四步完成一份班级报告

第一次使用先配置 AI；之后每节课只需要选择班级、代码文件夹和观察文本。

01

配置 AI 服务

进入左侧「设置」→「AI 服务」，选择供应商、填入 API Key、确认模型和地址，然后点「保存并测试连接」。

  • 支持 DeepSeek / MiniMax / 通义千问 / 智谱 GLM / OpenAI / Claude
  • Key 加密保存，页面只显示尾号
  • 思考模式默认关闭，省钱且更快
02

准备课程材料

在「报告工作台」选择班级，填写课程主题和日期，指向本节课的代码文件夹；也可以上传运行截图、代码截图和作业截图。

  • 有代码截图时可以跳过 AI 读代码
  • 有作业截图时可以跳过作业生成
  • 逐学生观察会用于个性化评价
03

批量生成内容

点击生成后，知识点、内容概述、作业/单词卡作为班级共享内容只生成一次；每名学生的评价再单独生成。

  • 共享阶段 4 次调用，全班复用
  • 学生评价并发生成，速度更快
  • 生成结果作为草稿可继续编辑
04

导出与交付

选择模板后导出 PDF 或 Word。默认模板可以在「设置」页或「模板管理」页指定，之后批量生成会自动选中。

  • 内置 classic / academic / cartoon / 科技前沿 / 素白极简
  • 支持自定义主题、字体、Logo 与截图
  • 导出文件保存在 data/reports
核心能力

围绕教学场景打磨，而不是通用聊天

从代码分析到家长可读的表达，每一步都有明确约束和本地数据掌控。

01

AI 内容生成

自动读取课程代码，生成知识点、内容概述、作业/单词卡与学生个性化评价。已填字段会被跳过，不重复消耗 token。

02

批量班级处理

共享内容只生成一次，逐学生评价并发生成；支持未到课学生排除和逐人观察文本。

03

模板与导出

内置多套模板，支持自定义主题、Logo、代码截图，一键导出 PDF 与 Word，版式适合直接发给家长。

04

安全与本地化

API Key 存在系统钥匙串或本地加密文件；用户设置、数据库和报告都留在自己的机器或挂载目录。

05

设置页集中管理

供应商、模型、密钥、默认模板、路径、图片转换参数都在页面里配置，保存后即时生效，无需重启。

06

低成本运行

默认关闭 DeepSeek 思考模式，一个 3 人班的生成成本约 0.027 元；需要更强推理时可临时打开。

容器部署

从 GitHub 拉取镜像运行

推送到 main 或打版本 tag 时，GitHub Actions 会自动构建 amd64 / arm64 镜像并推送到 GHCR。镜像公开，直接拉取即可。

拉取指定版本
docker pull ghcr.io/kylo94/course-report-generator:1.4.0
拉取最新版
docker pull ghcr.io/kylo94/course-report-generator:latest
用仓库提供的 compose 文件启动
docker compose -f docker-compose.ghcr.yml up -d
CRG_IMAGE_TAG=1.4.0 docker compose -f docker-compose.ghcr.yml up -d
日常运维
docker compose -f docker-compose.ghcr.yml logs -f
docker compose -f docker-compose.ghcr.yml down
# 升级：先 down，再改 CRG_IMAGE_TAG 或拉 latest，然后 up -d
./data数据库、用户设置、加密密钥、报告输出、截图与 Logo
config/app.yaml端口、数据库地址、报告目录等非敏感配置
挂载目录课程代码所在路径需要同时挂载进容器，路径要与页面里填写的一致

成本实测

默认关闭思考模式，省下约 70%

同一个 3 人班级、同一课程，在空闲时段用 DeepSeek 官方价格实测。思考模式默认开启时，推理 token 会按输出价格计费。

方案 输入 token 输出 token 推理 token 空闲成本
思考模式开启22,82117,64116,2590.093 元
思考模式关闭（默认）21,9781,25200.027 元

还能怎么省

  • 保持思考模式关闭；只有在遇到难判定的复杂内容时临时打开。
  • 已有代码截图时打开「跳过 AI 读代码」，直接省掉一次大输出调用。
  • 已有作业截图时打开「跳过作业生成」，单词卡不需要时可以关掉。
  • 已填好的知识点、内容概述、作业会被复用，不会重复请求 AI。
  • 避免频繁点「重新生成」；生成结果可直接在报告编辑器里手动修改。

收费口径按 DeepSeek 官方定价：输入 1 元/百万 token（缓存未命中），输出 4 元/百万 token（空闲时段）。

常见问题

使用前值得知道的事

必须联网吗？

AI 生成需要联网访问供应商 API；模板编辑、草稿保存、PDF / Word 导出都可以在本地完成。API Key 未配置时，页面仍可管理学生和模板。

API Key 保存在哪里？会不会明文写进文件？

优先保存在系统钥匙串（macOS 钥匙串 / Windows 凭据管理器），不可用时保存为本地 Fernet 加密文件。data/user_settings.json 不保存明文，接口只返回是否配置和尾号。

默认模板为什么之前总丢失？现在怎么保存？

旧版只存在浏览器 localStorage，清缓存或换浏览器就会丢。现在默认模板保存到后端用户设置，在「设置」页下拉框或「模板管理」页点「设为默认」都会持久化。

支持哪些 AI 供应商？

DeepSeek、MiniMax、通义千问、智谱 GLM、OpenAI 和 Anthropic Claude。设置页切换供应商后，记得同时更新对应模型的 API Key 和模型名。

思考模式要不要开？

日常生成建议关闭，省钱且快很多。遇到特别复杂、需要模型反复推敲的内容，可以在设置页临时打开；它只影响 DeepSeek，且会显著增加推理 token。

升级镜像会丢数据吗？

不会。用户设置、数据库、加密密钥和报告都在挂载的 ./data 目录里。升级时停止容器、拉取新镜像、重新启动即可。
