课程报告生成工具 macOS 启动说明
============================================================

本应用由 GitHub Actions 从公开源码构建，但未购买 Apple 开发者证书，
因此首次打开时 macOS 可能提示“来自身份不明的开发者”或“无法验证开发者”。

这不是病毒提示。你可以通过以下任一方式打开。

方法一：右键打开（最简单）
------------------------------------------------------------
1. 打开 DMG，将「课程报告生成工具.app」拖到「应用程序」。
2. 在「应用程序」中找到它，按住 Control 点击图标，或鼠标右键点击。
3. 在菜单中选择「打开」。
4. 弹窗中再次选择「打开」。

完成一次后，之后就可以正常双击运行。

方法二：终端移除隔离属性
------------------------------------------------------------
1. 打开「终端」。
2. 如果 App 已拖到「应用程序」，执行：

   xattr -cr "/Applications/课程报告生成工具.app"

3. 再双击运行 App。

如果 App 还在下载目录，把上面的路径换成实际路径即可，例如：

   xattr -cr "$HOME/Downloads/课程报告生成工具.app"

方法三：系统设置中允许
------------------------------------------------------------
1. 先尝试双击 App，看到阻止提示后关闭弹窗。
2. 打开「系统设置」→「隐私与安全性」。
3. 找到与课程报告生成工具相关的提示，点击「仍要打开」。

其他说明
------------------------------------------------------------
- DMG 中的「Applications」是快捷方式，把 App 拖到它上面即可安装。
- 所有安装包都由 GitHub Actions 构建，Release 页面提供 SHA256 校验值。
- 如需完全避免这类提示，需要有 Apple Developer 账号并进行签名与公证。
